# Analisis-De-EEFF
Analisis de la base de datos
Validacion de datos señalando inconsistencias, proyectando las ventas a 24 meses en tres escenarios (conservador, base y optimista) con supuestos explícitos y sensibilidad, proponiendo un plan de reducción de gastos con ahorro cuantificado, plazos y prioridades. Incluyendo flujo de caja, estado de resultados proyectado y punto de equilibrio, usando mediana, Pareto, bandas de incertidumbre y una simulación Monte Carlo simple.
